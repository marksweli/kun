## 讨论

- **淬火**：约 1 ms 时上表面出现等间距的横向裂纹，2 ms 时 11 条裂纹贯穿 TC 到达界面。随后裂纹在界面处偏折，沿界面向两侧扩展（3 ms 起），这和论文描述的"横向裂纹 → 界面裂纹 → 剥落"顺序一致。界面剥落的时间比论文慢，论文中 28 ms 已完全剥落。
- **加热**：TC 受压，但 Amor 分解中的偏量能和泊松效应仍会让上表面产生竖向裂纹（论文也报告了加热时上表面有损伤）。约 12 ms 时左端出现界面裂纹，与论文中 12 ms 开始剥落的时刻吻合。
- **界面韧性**：$G_i$ 越大，界面损伤越少；$G_i=0.004$ 时界面基本不开裂，裂纹停在界面处，趋势与论文 Fig. 21 一致。按 He–Hutchinson 准则（$R=0.25$），偏折的临界界面韧性为 $G_i^{c}=R\,G_c^{BC}=0.075$ N/mm。各工况的 $G_i$ 都远小于该值，所以裂纹偏折到界面，而不是穿入 BC。界面附近的 BC 没有损伤。
- **底部边界**：滚支时界面剥离由整体冷却驱动，约在 100 ms 才发生。固支时界面损伤更早出现（5 ms 达到 10%）。但固支底部长时间冷却后，BC 底层会出现一条人工损伤带（`max_d_BC`=1），所以界面以下的损伤不能作为物理结果解读。
